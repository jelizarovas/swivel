Before the first swivel

One boring—but important—paragraph.

Swivel needs Windows 10/11 Pro or Enterprise. Windows 10 Team cannot use the fingerprint reader. The app is unsigned, so Windows may ask whether you’re sure. You are still in charge of that decision.

Quietly useful

It lives in the tray.

Close Settings and Swivel slips into the notification area, where tiny useful apps belong. Hold the blue Swivel button for two seconds whenever you need Settings. It listens only while you’re signed in. No service. No account. No telemetry.
