# Swivel v0.1.3

The two-state icon release.

## Changed

- Replaced the continuous circular-rotation symbol with a curved, two-ended quarter-turn arrow: Swivel has two orientations, not infinite spin.
- Applied the new symbol to the EXE, notification-area icon, settings window, rotation bubble, website mark, and 3D demonstration.
- The download page now states the exact latest version and release date.

## Carried forward from v0.1.2

- **Right side down** maps to Windows portrait 90; **Left side down** maps to portrait 270.
- Settings save automatically and use touch-friendly Material-style chips.
- Native vertical touch panning, a rounded scrollbar, compact cards, and collapsed diagnostics.

Both executables remain unsigned early prototypes. The corrected right-side-down mapping still needs confirmation on the Surface Hub 2S.
